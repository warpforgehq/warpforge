Tasks that work on their own branch in the project folder now show their pull request too. The sidebar row and the task header display its number, whether it is open, a draft, merged or closed, and how its checks are doing, just like tasks that run in a separate worktree.

Creating a pull request closes the form and keeps its status available for project-folder tasks, including child sessions sharing their parent’s branch.
