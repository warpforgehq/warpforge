Settings got a cleaner, consistent layout. Every page opens with a clear title and a one-line summary, options sit in tidy cards with the name and explanation on separate lines, and switches, menus and buttons look the same everywhere. The settings list beside it is roomier too, with a proper title, a back arrow and a bigger search field.

Agents and their models now live in one place: each agent is a single row with its version, an Update button when one is available and an on/off switch. Click an agent to expand it and choose which of its models appear in pickers, or add your own model id. Memory settings and the memory browser now share one tidy page, with Memories and Proposals at the top.
