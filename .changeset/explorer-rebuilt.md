The Explorer is rebuilt for large projects. The file tree opens instantly, loads folders as you expand them, and updates live as files change on disk — including files agents create from the terminal — so they're ready to `@`-mention and show up in the Changes rail within a second. Changed files and their folders are coloured by git status; gitignored files such as `.env` stay visible but greyed out, and the eye button in the Explorer header hides them in every project.
