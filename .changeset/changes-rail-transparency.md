The Changes panel now shows the whole picture of your working copy. Files you have edited stay under "Changes", brand-new files that git isn't tracking yet get their own "Unversioned Files" group instead of hiding among them, and the eye button reveals everything your .gitignore covers when you need to check on a build output or a local config file. Projects that contain more than one checkout get a node per repository, each labelled with its own branch, so it is clear which repository a change belongs to before you commit it.
