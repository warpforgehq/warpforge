The branch list answers the two questions you open it for. Your main branch leads the list instead of hiding behind the folder groups, since it is where everything branched from, and the branch you are on is marked at the end of its row with a check rather than with a mark in front of the name that pushed it out of line with every other branch. The list is set in the same type as the rest of the window instead of a code face, its rows are tighter, and the redundant "Branches" heading above "Local branches" is gone.
