Your task's branch, commits and pull request now live in one place: the task's **Diff**.

- **See every commit on the branch.** The new **History** tab lists the branch's commits and marks the ones not pushed yet. Click a commit to see only its changes; close the chip in the Diff header to get back to your working changes. Press ⌘⇧K (Ctrl+Shift+K) to jump straight there.
- **Push and open a pull request without leaving the task.** **Push** shows how many commits will go out, with force-with-lease one click away. **Create PR** opens the form right in the Diff, pushes first if needed, and can draft the title and description from the branch's commits, including after you have already pushed.
- **Follow the pull request from the task.** Once it exists, its number, state and checks show in the sidebar, the task header and the Diff, for tasks in their own worktree and for tasks working on a branch in the project folder.
- **Review it in Warpforge.** Click the pull request badge to open it in the task's **Pull request** tab, with the same files, threads and review actions as the Inbox. ⌘/Ctrl-click or the ↗ button opens it on GitHub instead.
