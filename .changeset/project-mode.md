Open a project to focus on it. Clicking a project in the task list, a pinned project on the rail or the project switcher now narrows the sidebar to that project: its Backlog, Pull requests, Explorer, Runtime and Terminal as one-click sections with counts and a running/failed light, and below them only that project's tasks, with a + to start a new one there. The section you pick fills the whole window with no tab bar, and each project remembers where you left it. Press ‹ beside the project's name, or Tasks on the rail, to go back to all projects.
