The sidebar now has three modes at the top — **Tasks**, **Inbox** and **Smiths** — that switch both the sidebar and the main view, with **⌥⌘1**, **⌥⌘2** and **⌥⌘3** as shortcuts. Mission Control, Automations and Memory sit below them and change only the main view, so the list you were working from stays put. **Tasks** shows how many tasks need you, and Warpforge reopens on the mode you left.
