The backlog and the pull request inbox load much faster. Your board shows right away and fills in GitHub's latest as soon as it arrives, instead of waiting on GitHub before showing anything. GitHub works the same whether you pasted a personal access token or just ran `gh auth login`, so a token is now optional. Repositories cloned through an SSH alias like `git@github-work:team/repo` are recognized too.
