Pushing and opening pull requests now happen right in a task's Diff, without a separate dialog. A new **History** tab lists every commit on the branch and marks which are already pushed; click one to see only that commit's changes, then close the chip to return to your working changes. A small **Create PR** button in the Diff header opens the pull request form in place, and once the pull request exists the same spot shows its status. Press ⌘⇧K (Ctrl+Shift+K) to jump straight to the History tab.

Switching between commits that change the same file now always shows the selected commit’s code, even when syntax highlighting is delayed or unavailable.
