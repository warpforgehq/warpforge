Browser bench fixtures

Each page has one task and one success code. The code only appears after the task is done.

  • Long article — find and press the one button near the bottom.
  • Signup form — fill every field and submit.
  • Modal dialog — edit the address in a modal, then close it.
  • Delayed results — results load after a spinner.
  • Covered button — a cookie banner covers the target.
  • Infinite list — find item #57 in a list that loads on scroll.
