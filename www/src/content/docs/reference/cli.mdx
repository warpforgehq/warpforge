The Rust binary installed as `wf` (via `install.sh`, from published archives — macOS Apple Silicon only for now) runs the Warpforge daemon. It does not install the desktop app. Projects, configs and agents are managed in the desktop app.

```bash
warpforge daemon   # run the local daemon explicitly
```

| Command | Flags | Description |
| --- | --- | --- |
| `warpforge daemon` | `--dev` | Run the local daemon that owns projects, services, agents, and task state behind a WebSocket API. The desktop app bundles and starts this automatically — running it by hand is for development. `--dev` binds a fixed local port without an auth token so a browser dev build can connect. |

Running `warpforge` with no command prints help.
